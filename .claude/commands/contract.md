1. Run `npm run drill -- contract <code or client name>`. A partial name works; if more than one matches it lists them, ask which.
2. Lead with the money line (claimed, signed off and unclaimed, not signed off), then anything out of date (programme of work, water licence).
3. Offer the next step that fits: `/claim`, `/pending`, or `/holes`.
