---
description: Draft a polite chase to a client's site geologist or superintendent for plods past the sign-off window, with each plod, its date and what it holds back.
---

1. Run `npm run drill -- pending --json` and take the client's plods that are past the window.
2. Run `npm run docs -- plod` so the plod sheets are ready to attach.
3. Write the email to `drafts/signoff-<contract>-<date>.md`: who it is to (the client contact on the contract), each plod (number, rig, date, shift), and one line asking for sign-off or a note of anything they want changed. Plain and short. No blame.
4. Never send it. Say where the draft is.
