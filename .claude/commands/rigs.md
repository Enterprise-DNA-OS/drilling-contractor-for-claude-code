---
description: Every rig: where it is, metres this week, last plod, engine hours, hours until the next service, and the bit on it.
---

1. Run `npm run drill -- rigs`.
2. Call out any rig past its service, and any rig marked working with an old last plod. One rig in detail: `npm run drill -- rig <code>`.
3. A rig moving to the workshop or standby: `npm run drill -- rig-status <rig> workshop|standby|working`.
